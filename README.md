# Movie Web Scraping Project

## Project Description

This project collects primary movie data from an external website using Python web scraping.

## Objective

The main objective of this project is to collect 2000+ movie records from an external website and save the collected data as a CSV dataset.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas

## Dataset Attributes

The collected dataset contains:

- Movie Title
- Release Year
- Rating
- Movie URL

## Output

The scraped data is stored in:

movies_dataset.csv

## Source Website

https://www.filmfansite.org.uk/date.htm

## How to Run

Install the required libraries:

pip install -r requirements.txt

Then run:

python scraper.py
